# content/

Ready-to-use content that ships with GameTable.

## adventures/

Importable campaign **bundles**. Each adventure is a folder you can read and edit,
plus a packed `.zip` you can import directly (**Campaigns → Import bundle**).

- **[the-sunless-shrine/](adventures/the-sunless-shrine)** — a free CC BY 4.0
  Dungeons & Dragons 5e one-shot for four 2nd-level characters (~2–3 hours), with an
  original map, tokens, handouts, SRD stat blocks, and full DM notes.
  Import [`adventures/the-sunless-shrine.zip`](adventures/the-sunless-shrine.zip).

New to bundles? See the [bundle format](../docs/BUNDLE_FORMAT.md) for the layout and
how to author or re-pack one.
